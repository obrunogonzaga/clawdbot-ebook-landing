Preciso saber programar? +

Não! O ebook explica tudo passo a passo. Se preferir zero complicação, a consultoria faz tudo por você.

Quanto custa usar depois de instalado? +

Você usa sua própria chave de API — se já tem conta na OpenAI ou Anthropic, é só conectar. Não precisa comprar API adicional nem pagar mensalidade para a Widia. O custo médio fica entre R$10-30/mês dependendo do uso, cobrado diretamente pelo provedor de IA que você escolher.

Funciona no meu celular? +

Sim! Você interage via WhatsApp, que funciona em qualquer celular. A Widia roda em um servidor (seu computador ou cloud).

É seguro? Meus dados ficam onde? +

Seus dados ficam no seu próprio servidor/computador. Você tem controle total. Nada passa por servidores de terceiros além da API de IA.
